# 动效原理手册（AI 科普 / 向晓 AI）

做视频前先读这份。它是把 video-shotcraft 的 124 张镜头卡和审美准则（`src/vendor/shotcraft/`，在线画廊 https://vincentwei1021.github.io/video-shotcraft/ ）吃透后，按**科普用途**重新整理的原理和配方。
**代码自己写**（`src/science/`），不在别人的模板上改字；需要看某个手法的参考实现时，去 `src/vendor/shotcraft/<分类>/<卡名>/` 读源码，只学原理。
已验证（2026-11-02）：照这套原理自己写的三个镜头（碎片聚合 / 分层爆炸 / 注意力飞线）质感不输原版。

## 一、十条总原则（每个镜头交付前逐条自查）

1. **没有匀速运动**。入场用强 ease-out，出场用强 ease-in，换位用不对称 in-out（起步干脆、落点很软）。速度感来自加速度，匀速 = 廉价 PPT。例外只有：扫描线、跑马灯、背景漂移这类“机器节奏”。
2. **一个镜头一个主角，动作弧完整**：起（出现）→ 承（悬停 / 展示）→ 落（落座 / 收束）。开场尤其只给一个主角。
3. **关键信息落定后停一拍**：要观众记住的画面（标题、结论、数字）静止 ≥1 秒再切；群体入场满板后停 0.5 秒。第一版几乎总是偏快——默认放慢一档，主体动作弧 ≥3 秒。
4. **舞台要布光**：渐变底 + 主光（顶部偏一侧）+ 余光（对角冷色）+ 可选地平线光带 + 暗角 + 胶片颗粒（`kit.tsx` 的 `<Stage>`）。纯色底 = 没布光。
5. **有重量**：落座要有“咔哒”——过冲回弹、整组下压几像素再弹回、接触影收紧变实。没有落锤的合体读作软趴趴的淡入。**不用震屏代替重量**（震屏全片 ≤3 处）。
6. **快速运动加方向模糊**：按这一帧的位移算模糊量和方向（`SpeedBlur`），静止时自动归零。只包快速段，慢速段包了会把字抹软。
7. **文字要么能读、要么是纹理**：要读的字 ≥56px（辅助文字 ≥32px，按最终渲染像素算，3D 里要乘透视压缩）；读不清的宁可删掉。3D 场景里的标注要活在同一个 3D 空间里（跟相机走、正对镜头），不能贴在屏幕上。
8. **光效宁缺毋滥**：扫光 / 泛光 / 高光全片 ≤2 次，只给主角，必须裁进圆角边界；不群发（每张卡闪一下 = 廉价模板）。
9. **一种手法全片只当一次主角**：同类手法（飞入、堆叠、翻牌、聚光、整墙点亮）同片只用一次；高能手法（急推、震屏、负片、白闪）严格配额（见第五节）。
10. **确定性**：动画只由帧驱动；随机数只用 `random(seed)`；不用 CSS 动画、`Math.random`、`useFrame`。

## 二、通用技术配方（拿来就用）

| 配方 | 做法 | 用在哪 |
|---|---|---|
| **缓动表** | `kit.tsx` 的 `EASE`：in（0.16,1,0.3,1）入场；soft 次要跟随；move（0.65,0,0.35,1）相机换位；out（0.7,0,0.84,0）出场；settle（0.34,1.45,0.64,1）冲过头再回；land（0.42,0,0.3,1）长减速落位 | 所有运动 |
| **弹簧** | Remotion `spring({damping 12–15, stiffness 110–220})`；一次可见过冲 = damping 13 左右 | 弹出、炸开、落座 |
| **一条进度驱动多通道** | 位置、缩放、角度、模糊、透明度全部由同一个 p 算出；分开写曲线（哪怕一样）会错位 | 相机机动、入场三通道（opacity + translateY + blur） |
| **距离驱动多属性** | `d = |i - pos|`，scale / opacity / blur / 颜色都从 d 推出；pos 是连续量 | 轮播、滚轮、焦点列表、景深 |
| **相机 = 姿态的逆变换** | 每站只写物体自己的 pose；相机 `scale(1/s) rotateZ(-rz) rotateY(-ry) rotateX(-rx) translate3d(-x,-y,-z)`，顺序严格反着来 | 3D 空间飞行、多站巡览 |
| **飞行途中拉远（hop）** | 站间飞行时相机额外拉远 8–30%（sin 包络），让观众瞥见全貌 | 多站巡览 |
| **错峰越来越快** | 起跳帧 = `start + stagger(i, n, span, EASE.out)`，间隔先大后小；绑物理隐喻（发牌、码一摞） | 批量入场 |
| **波纹错峰** | delay ∝ 到波源的距离（曼哈顿或欧氏）；单个元素行程恒定 | 碎片聚合、点阵点亮 |
| **预备拍** | 大动作前先反向回拉 3–5%（anticipation），只做段落级一次 | 急推、发射、炸开前 |
| **拖拽层级** | 收尾时主体先停、阴影晚 3f、残影最后消散；全部同帧冻结读作机械 | 所有落定 |
| **悬空同形软影** | 元素悬空时在原位画一个模糊压暗的同形影子，blur / offset / opacity 随高度变（高 = 大而糊而淡，落地 = 重合消失） | 3D 贴落、分层爆炸 |
| **按朝向打明暗** | 面越侧对镜头越暗：`shade ∝ 1 − |cosθ|`；转到侧棱最薄时掠过一道受光带 | 碎片、翻牌、3D 卡 |
| **光斑底噪** | 2–3 团大径向渐变（screen 叠加，不做实时 blur），双正弦不等周期漂移；结尾必须缓动收敛到静止，不能硬停 | 暗场氛围 |
| **共振** | 事件发生的同一帧，氛围层同步响应（落点帧附近的光斑涨亮）；错 2f 以上就读不出来 | 飞线落点、数字落定 |
| **飞线** | 贝塞尔采样成点，按进度长出；光头 + 彗尾领跑（只在生长期挂载）；到站后落点脉冲 + 冲击环，再淡成细虚线 | 关系、数据流向、注意力 |
| **生命曲线** | 透明度不是简单淡入淡出：`[0,1,0.5,0.2,0]`，前 1/4 猛亮、中段压暗让位、末段拖尾 | 穿梭的背景词、粒子 |
| **描画** | SVG `pathLength={1}` + `strokeDashoffset 1→0`；加笔头（渐细短 dash + 笔尖圆点）才像“有人在画” | 圈注、下划线、流程线、字标 |
| **擦入而不是淡入** | 颜色 / 新状态用 clip / mask 擦入，不做透明度混合（半透明叠在暗底上会过一段脏灰色） | 翻色、点亮、显影 |
| **硬切藏点** | 切点藏在遮挡、撞击、白闪或光峰的 1–3 帧里；切点暴露在静止帧上就穿帮 | 转场 |
| **时间操纵** | 帧号非线性 remap（斜率 = 速率）：定格、顿帧、子弹时间；同一镜头只能有一个时间操纵者 | 强调、高潮 |
| **条件挂载** | 透明度到 0 的东西要真的卸载（`{show && …}`），否则永远不是真静止 | 光头、残影、冲击环 |
| **小画布作画** | 大面积渐变 / 模糊画在 480×270 上再 scale(4) 铺满，代价是全屏的 1/16 | 渐变背景、大光斑 |

### 性能（渲染一律在 GitHub Actions 上并行，但也别浪费）
- 不要给铺满全屏的层加每帧变化的 `filter: blur()`（实测慢 3 倍以上）；模糊挂在小元素上。
- 不用 `@remotion/effects` 这类 WebGL 特效、`CameraMotionBlur` 多重采样，除非必要：慢，而且在近静止帧会把画面染灰；带它的镜头多页并行渲染会卡死（`preview.yml` 已用 `--concurrency=2 --timeout=240000`）。
- `backdrop-filter` 可以用，但祖先不能有 filter / opacity<1，否则看不到背后的光。
- 3D 里的文字发糊先查栅格化：放大用 CSS `zoom`（布局级），不用 `transform: scale` 先缩后放。

## 三、手法目录（按科普用途）

每条：做法要点 → 关键参数 → 坑。括号里是 video-shotcraft 的卡名，参考源码在 `src/vendor/shotcraft/` 同名目录。

### 1. 开场钩子（第一镜，抓住人）
- **碎片聚合**（fracture）✅ 已实现 `ShardOpen`：海报切成网格，碎片三维散布 → 按离中心距离一圈圈归位（每圈错峰 ~5f，单块 26f 长减速）→ 落位阻尼小摆 → 亮字停一拍、整面推近 3% → 背离中心加速飞出。坑：退场是飞走不是淡出；hold 段是唯一读字窗口。
- **星芒闪现、卡片弹射**（magician-card-flourish）：X 形针状光束旋转 + 中心小亮点 0.3 秒 → 卡片从闪光点极远处真透视弹射、自旋随靠近衰减 → 硬定格 + 同形光脉冲 + 一次扫光。坑：细光束别放进运动模糊（会拆成条纹分身）。
- **关键词穿梭**（flying-words）：关键词按黄金角铺在扁椭圆截面上，沿 z 从远处飞来擦身而过，生命曲线 `[0,1,0.5,0.2,0]`，越近越往画外甩、近端加失焦。只做背景层，前景放标题。中文词要缩字号。
- **数据流线地景**（dataviz-landscape-open）：暗场多条流线汇入主干、标签浮在线上、相机重景深低速飞越。亮度按层拉开，中景是主角层。
- **预告片速剪**（trailer-bumper）：三镜各 9f 速剪 + 纯黑静默一拍，再出标题。黑场必须纯黑无物。
- **聚光锁定**（spotlight-hero-card）：关灯的画面里一束光池游走 3 站后锁定主角，推近、主角抬起悬浮、轮廓光、落回。开场只给一个主角。
- **升降臂揭示**（crane-rise-reveal）：从一行特写起，相机减速升起后拉，内容行行涌入直到全景；被追踪的那行先实、其余压到 38%。
- **字形窗口冲入**（text-as-mask）：超粗大字当窗口，字里透出流动的画面，吸一口气后字形指数放大 46 倍溢出、窗内画面接管全屏。窗里要有大块饱和色和亮线。
- **断笔成字**（stroke-segment-build）：标题拆成十几段笔画乱序点亮，前 70% 不可读，末段落位瞬间语义成立。只适合观众认识的短词。

### 2. 讲结构（“它由什么组成”）
- **分层爆炸图**（exploded-view）✅ 已实现 `LayerExplode`：轴测平躺（rotateX ~56°、rotateZ ~−36°）→ 各层沿法线弹簧错峰炸开（顶层先、飞得最高）→ 悬停期相机环绕 +10° 读出层间视差 → 标注在 3D 里、贴着各自那层左右交替 → 标注先撤、逆序合体、落锤（整组下沉回弹 + 接触影收紧）+ 一道扫光。坑：深度线索三件套（地面影随高度变虚、厚度边、底板插槽虚线）缺一层次就糊。
- **克隆纵队**（cloner-depth-echo）：主体瞬间复制出一串半透明分身沿斜向纵深排开，停一拍再加速吸回合一 + 弹跳。适合讲“同一个东西有很多份 / 多头”。
- **级联生成树**（canvas-materialize-moves 的 diagram-cascade）：根节点 → 子 → 孙逐层弹出，连线先于节点生长（彗星头先行 10f），相机从根特写拉远揭示全树，成树后整棵呼吸一拍。适合讲层级、分类、推理链。
- **蓝图描线成形**（wall-reveal-moves B）：先用细线描出线框，再一条发光竖线扫过、扫过处线框实体化。适合“从设计图到实物”。
- **3D 空间巡览**（basic-3d-scene）：几张卡散在 3D 空间，相机按逆变换逐站飞过去对齐，途中拉远，最后拉到总览。适合讲“几个部分各是什么”。

### 3. 讲过程、流程、原理
- **飞线接力**（glow-flyline-moves C）✅ 已实现 `AttentionRelay`：暗场光斑底噪 + 玻璃节点；发光弧线从源头射向目标（弱的先快射、强的压轴），落点脉冲 + 冲击环 + 光斑同帧共振，到站后淡成虚线。坑：三条以上纯飞线连打读作大屏模板，必须有共振。
- **汇聚吞并**（bezier-source-converge-merge）：几个来源各一条贝塞尔曲线连向同一汇聚点，曲线错峰描出，节点沿真实曲线滑向汇聚点并三段式加速缩小到消失（后 1/4 行程掉光 = 被吸进去）。适合“多个输入合成一个输出”。
- **中枢连线**（integration-hub-map）：中心翻面落定 → 周围图标同帧弹现 → 光管同帧齐连 → 管内脉冲持续流动。“同时”是它的节奏身份（错峰版被否过）。
- **扫描装配**（scanline-assemble-flyin）：蓝图画板上一条扫描线匀速扫下，扫到哪个槽位，那个组件就从画外飞入过冲贴合 + 角标咬合。适合“一步步搭起来”。
- **扫描标注**（scanline-annotate-focus）：扫描线掠过，越过哪块区域的下缘，哪块就被四角取景框弹簧收拢对准、贴出机器标签。两套颜色严格分工：内容色 vs 机器色。
- **线条接力转场**（line-carry-transition）：一条线从上个画面延伸出画，镜头跟线横移，线在移动中拐角围出下一个画面的框——全程无剪切。线的生长速度必须等于镜头速度。
- **3D 终端飞行**（terminal-3d）：几个窗口散在 3D 空间，相机窗间飞行，每到一窗打字、结果逐行滑出。讲“执行步骤”。
- **打字过滤**（type-and-filter）：搜索框逐字打字 → 网格收敛成一张卡 → 点击穿透进详情。打字按 3f/字起稿。

### 4. 讲数据、数字
- **仪表扫针**（needle-sweep-selftest）：表盘点亮 → 指针去程 12f 甩满全弧（扫过的刻度依次点亮）→ 弹簧回程过冲落到真值；落定同帧数值弹出。
- **滚带定针**（tape-scroll-fixed-pointer）：针不动、刻度带滚过，冲刺 → 弹簧刹车停位。讲“数字大跳变”。
- **点阵集群重组**（unit-dot-swarm-regroup）：几百个点三幕弹簧迁徙，终幕拼成数字。讲“每个点是一个人 / 一个参数”。
- **示波流线 / 爆轴重标**（chart-live-moves A/C）：曲线右端实时写入 + 突发尖峰；新值冲出画框逼 y 轴重标（“off the charts”字面化）。尖峰和爆轴全片各一次。
- **子弹时间**（bullet-time-freeze-orbit）：图表长到一半连同飞溅的火花一起冻住，相机绕面板扫 52° 再回，时间恢复接着长完。给“最值得停下来看”的那个数字。
- **数字滚动**：读数从 0 数到终值（expo-out，与运镜同帧收），落定瞬间 overshoot 弹出；读数 120–176px。
- **点阵波纹**（radial-wave）：点阵按距离错峰点亮、过冲到 1.5 再落回；第二道波反向收拢。讲“扩散、传播”。
- **数值梯度**（value-stagger-gradient）：一排柱子的高度 / 色相 / 位移 / 模糊各自铺成梯度；第二拍把错峰原点换到中心。

### 5. 讲对比（以前 vs 现在、A vs B）
- **前后拉杆**（before-after-slider-scrub）：两版同布局叠放，分割杆先猛甩后慢扫，杆过处新版显影；慢扫停在 40% 留着对比。两版必须同布局同机位。
- **对撞开屏**（versus-slam）：左右两半带斜切边加速对冲撞合，撞击帧白闪 + VS 盖章，切点就是撞击本身。
- **翻牌揭示**（card-flip-reveal）：卡片沿 Y 轴翻 180°（预备后仰 → 过冲 194° → 回弹 180°），翻到侧棱最薄时掠过受光，背面揭出大号结论数字。正反面必须语义成对（问题 → 答案）。
- **空心字前后读数**（outline-word-fill）：空心大字急缩落位，虚线大圆收拢，左右虚线带“之前 / 之后”读数，实心字一帧硬切点亮。只适合一个短词。

### 6. 讲历史、时间线
- **时间轴穿行**（timeline-travel）：镜头沿水平刻度轴加速掠过，每过一格卡片弹立短停，末刻度急停推近。末段先留 ≥30f 静止再倒推行程；掠过速度要保证最后两张能读。
- **长卷急刹**（changelog-scroll-brake）：高速长卷指数减速精准停在目标行，目标抬升、其余退暗到 38%（不退到 0）。高速段内容不用可读。
- **倒计时表盘**（countdown-arc-scatter）：数字沿大弧切向排布，整盘扫动后弹簧急停，目标数字平移落成标题首字。

### 7. 强调关键词、金句
- **关键词彩光充能**（gradient-word-sweep）：句中一个词被渐变彩光从左到右扫过充能，波前最亮向后衰减，填满后字符间偶发细闪电。泛光宁弱勿强；禁跟随光点；只有这个词动。
- **马克笔下划线**（marker-underline-title）：标题落定后 4–8f，关键词下一笔变宽、毛糙、跟字势的笔画 8–12f 画完。
- **逐词三通道入场**（blur-slide）：opacity / translateY / blur 共用一个 p；中文要按语义手动分词，词级比字级更有“念出来”的语感。✅ 简版在 `kit.tsx` 的 `Rise`。
- **花括号撑开**（brace-expand）：一对小括号弹开、文字被拉开的幕布从中间揭示。全片唯一一次过冲。
- **准星锁定**（reticle-lock-on）：四个 L 形角标从画外飞入、超调回弹咬合目标。一支片 ≤2 次。
- **定格圈注**（speed-ramp-freeze）：画面流动中突然定格（快门白闪 3f + 取景框四角），马克笔一笔圈住目标 + 批注，再解冻。≤2 次。
- **词槽轮换**（pill-slot-cycle / vertical-word-roll）：句干钉死，句尾词像老虎机一格格换；每拍前 8f 换位、后 13f 静置让人读。

### 8. 转场（一个接缝只用一式）
- **推进流白**：前镜推进，切点跨骑一层白闪。能量相近的画面之间。
- **甩镜**（whip-pan）：机位一拍横甩，中段糊到不可辨时换景，落点前急刹。快节奏段。
- **穿窗**（mask-wipe）：画面里的一个元素放大成全屏窗口，新场景从窗内长出。“点开它进入它的世界”。
- **字形穿越**（letterform-zoom）：镜头钻进巨型章节标题的笔画换景。招牌转场，全片 ≤1 次。
- **圆心光圈切**（circle-match-iris）：从上个画面的圆形元素圆心炸开光圈，圈内新画面的圆环接在同一个圆上。两景的圆心必须严格是同一组常量。
- **3D 百叶窗**（blinds-slice）：12 根叶片错峰翻面成波。边界必须带亮线，否则读作 PPT。≤2 次。
- **故障撕裂**（glitch-displace）：横条错位抖动中硬切；条带不碎块。
- **前景遮挡隐形切**（invisible-cut）：失焦前景物横扫，盖满全屏那一帧硬切。最无痕。
- **暖色漏光**（light-leak-burn）：光峰吞掉旧画面七成时硬切。算一次光效。
- **底边上推换章**（bottom-push-stack-wipe）：新章连底色整屏从下往上把旧章顶出去，适合做全片章节骨架（方向全片统一）。

### 9. 收尾
- **全员合影**（outro-group-photo-launch）：全片出现过的元素从四面八方飞来围住字标，相机落下 + 舞台光 + 金尘。收尾默认加码一档，是全片能量峰值。
- **颗粒爆散凝聚**（grain-dissolve）：整行字爆成沸腾颗粒，再凝聚成发光短字标（feTurbulence + feDisplacementMap 驱动）。
- **拉远孤立**（pull-back-isolation）：从主角特写后拉，周围元素按距离错峰熄灭，主角悬在暗场中央。“全片只为这一个结论”。
- **减法收尾**（ui-strip-away-outro）：界面从外到内层层蒸发，只剩一个东西滑到中央放大。
- **霓虹跑马灯 recap**（neon-triple-marquee）：三行关键词对向横滚、轮流点亮。可作合影前的铺垫。

## 四、科普视频的能量曲线

低开（钩子一镜抓住人，但不炫到顶）→ 中段按“讲一个点 → 呼吸 → 讲下一个点”交替推进 → 结论段给一次最强的强调（子弹时间 / 彩光充能 / 拉远孤立选一）→ 收尾峰值。
每个知识点配一个镜头，镜头之间用转场；同一个手法不当两次主角。

## 五、全片配额（超了就换手法）

| 手法 | 上限 |
|---|---|
| 全画面级冲击（震屏、负片、整画面 scale 泵、闪帧） | ≤3 处 |
| 光效（扫光、泛光、聚光、漏光） | ≤2 次 |
| 急推（crash zoom） | ≤2 次 |
| 暗场段（如果主视觉是浅色） | ≤1 段；进出用藏切转场 |
| 几何擦除 / 体块转场 | 各 ≤2 次 |
| 招牌转场（字形穿越、线条接力） | ≤1 次 |
| 主题切换、定格圈注、准星锁定 | 各 ≤1–2 次 |
| 时间操纵（定格、顿帧、子弹时间） | 同一镜头只能有一个 |
| 标题入场手法种类 | 同片 ≤2 种 |

## 六、工作流

1. 读这份手册 + 稿子，给每段口播选“用途”和手法（第三节），写进分镜。
2. 在 `src/science/` 自己写镜头组件：文案、配色、数值都做成 props（默认值是示例），公共件放 `kit.tsx`。
3. 本地只渲染几张单帧（`remotion still`）自检：构图、字号、穿帮、读字时间。
4. 用 `preview.yml`（GitHub Actions，每个镜头一台机器）渲染，发到 Telegram 看。
5. 交付前对照第一节十条和第五节配额自查。
