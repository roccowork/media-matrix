# 案例 2：对外 AI 客服 / 外贸询盘回复

虚构公司「海程示例家纺」，山东滨州的毛巾和床品出口工厂。

| 文件 | 用途 |
|---|---|
| [资料/](资料/) | 4 份公司资料，上传到新的知识库 |
| [测试询盘.md](测试询盘.md) | 多轮对话、多语言、转人工、不乱答、安全 5 组测试 |

## 这个案例学什么

| AI 技术 | 在这里怎么体现 |
|---|---|
| 多轮对话与记忆 | 客户说「3000 条」「加 Logo 呢」，AI 要记得前面说的是浴巾 |
| 意图识别 | 先判断客户想干什么：问产品、砍价、投诉，再走不同的流程 |
| 跨语言检索 | 资料是中文，客户用英语、西班牙语、俄语问，也要答对 |
| 转人工 | 砍价、投诉、大单交给销售经理，AI 负责收集客户信息 |

## 流程

```
开始 → 问题分类器
        ├ 产品咨询 / 询价 → 知识检索 → 有资料？→ LLM（带记忆）→ 回复
        │                                └ 没有 → 说明并可转人工
        └ 砍价 / 投诉 / 大单 / 代理 → LLM（用客户的语言写转人工话术，收集联系方式）→ 回复
```
